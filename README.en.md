**AI Tooling · Local-first Software · Linux Desktop**

I enjoy making existing software safer, more practical, and easier to use in real-world environments, while also building small tools for problems I personally encounter.

## Currently focused on

- **AI Agent / OpenClaw tooling** — control centers, runtime status, usage visibility, automation, and local security boundaries
- **Linux desktop** — GNOME desktop experience, application icons, and everyday workflows
- **Local-first engineering** — keeping data, configuration, and runtime state local whenever practical, with understandable and recoverable defaults
- **Automation & CLI** — turning repetitive operations into reliable tools with Python, TypeScript, and Shell

## What I care about

```text
Useful > flashy
Safe defaults > hidden surprises
Local-first > unnecessary cloud dependency
Maintainable improvements > unnecessary rewrites
```

I care about whether software is genuinely useful: whether defaults are safe, system state is understandable, failures are recoverable, and long-term maintenance remains reasonable.
